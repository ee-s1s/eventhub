# ⚡ Smart Event Check-In & Gate Management System
> نظام متكامل وذكي لإدارة الحضور والتذاكر للفعاليات، يعتمد على المسح الفوري لأكواد QR والتحديثات اللحظية والتفاعل مع الطابعات الحرارية والواتساب.

---

## 📖 نبذة عن النظام
نظام إداري عالي الأداء مصمم لإدارة البوابات وتنظيم الحضور في الفعاليات والأنشطة المختلفة. يتيح للنظام مسح التذاكر بسرعة، المزامنة اللحظية لحالة الحاضرين (بالداخل / بالخارج)، إدارة وتعديل السجلات، بالإضافة إلى طباعة التذاكر حرارياً وإرسالها عبر WhatsApp بنقرة واحدة.

---

## ✨ المميزات الرئيسية

* **📊 لوحة تحكم وإحصائيات حية (Live Dashboard):**
  * حساب فوري لإجمالي المقيدين، المتواجدين بالداخل، والمتبقين بالخارج.
  * مؤشر بصري يوضح نسبة الحضور الفعلية تلقائياً دون الحاجة لتحديث الصفحة.

* **📷 عدسة المسح السريع (QR Scanner Engine):**
  * واجهة مسح للكاميرا مخصصة للبوابات للتحقق من صلاحية التذكرة وتسجيل الدخول/الخروج لحظياً.

* **🔍 محرك بحث وفلترة ذكي (Smart Search & Filters):**
  * بحث فوري بناءً على الاسم، رقم الهاتف، البريد الإلكتروني، أو كود التذكرة.
  * فلترة السجلات حسب الحالة: **الجميع** | **بالداخل** | **بالخارج**.

* **🖨️ طباعة وإرسال التذاكر:**
  * دعم كامل للطباعة الحرارية السريعة (Thermal Printing) لطباعة التذاكر عند البوابات.
  * مشاركة وإرسال التذاكر مباشرة عبر رابط **WhatsApp** مخصص لكل حاضر.
  * إمكانية تحميل صورة الـ QR Code الخاصة بكود التذكرة.

* **📁 إدارة واستيراد/تصدير البيانات:**
  * استيراد قوائم المدعوين دفعة واحدة عبر ملفات **Excel / CSV**.
  * تصدير التقرير الحالي لبيانات الحضور بصيغة **CSV**.
  * إضافة، تعديل، وحذف الحاضرين فوريًا مع دعم حماية CSRF والتحديث الديناميكي للواجهة (AJAX).

## 🛠️ التقنيات المستخدمة (Tech Stack)

### Backend
* **Python** (Django / Flask Framework)
* **SQLite / PostgreSQL** لإدارة قاعدة البيانات

### Frontend
* **HTML5 / CSS3** (نظام تصميم داكن فاخر - Cyberpunk Dark Theme)
* **JavaScript (Vanilla JS / Fetch API)** للتحديثات اللحظية بدون إعادة تحميل الصفحة
* **FontAwesome 6.5** للأيقونات
* **Google Cairo Font** للخطوط العربية
